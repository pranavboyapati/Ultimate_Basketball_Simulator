## Overview

Ultimate Basketball Simulator is a fast-paced, 1-on-1 basketball game developed in Unity using C#. Dribble, shoot, and score your way to victory in this engaging simulation inspired by classic “Make It, Take It” playstyles.

## Installation & Setup

Clone the repo and open the Unity project:

```bash
git clone https://github.com/pranavboyapati/Ultimate_Basketball_Simulator.git
cd Ultimate_Basketball_Simulator
```
Then, open the project using any version of the Unity Editor released after 2021.
